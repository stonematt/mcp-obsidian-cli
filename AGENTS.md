# Agent instructions

Installing mcp-obsidian-cli for a user: run the install prompt in the README's
[Install](README.md#install) section. That prompt is the install path.

Do not hand-write `claude_desktop_config.json`. The config block in the README
is a manual fallback for when the prompt fails — not a first move.

Full runbook, including failure modes: [docs/INSTALL.md](docs/INSTALL.md).
